# BantuBeres Guru AI

Workspace AI untuk membantu guru SD, SMP, SMA, dan SMK menyiapkan pembelajaran dari satu konteks proyek.

## Fitur
- Project Builder: jenjang, kelas, mata pelajaran dinamis, topik, pertemuan, metode, karakter siswa, sumber daya, target, instruksi.
- Peta perjalanan pembelajaran per pertemuan.
- Modul Ajar, LKPD, Asesmen Soal, Strategi Pembelajaran, Bahan Ajar, Rubrik Penilaian, Panduan Presentasi, Peta Konsep.
- Generate ulang tanpa mengubah pilihan untuk membuat versi pembanding.
- Ngobrol Bareng AI dengan gaya santai tetapi kritis.
- Gemini API key / OAuth token disimpan lokal di browser.
- Training knowledge dasar dari paket TRAINING_AI_GURU_PROFESIONAL terintegrasi sebagai system context.

## Catatan keamanan
Versi ini menggunakan kredensial langsung di browser agar pengguna tidak perlu login. Untuk produksi skala besar, gunakan server-side proxy/secret manager.
